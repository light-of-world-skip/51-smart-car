# 基于51单片机的智能循迹与蓝牙遥控小车

> 一个基于8051单片机，支持红外循迹与HC-05蓝牙遥控双模式切换的智能小车项目。
## 📋 项目概述
本项目以51单片机为核心，采用C语言模块化编程，实现了小车的自主循迹行驶与手机蓝牙遥控功能。代码采用了非阻塞状态机、环形缓冲区、PD控制算法等工程实践，保证了系统的实时性与稳定性。
- **双模式切换**：支持“红外循迹”与“蓝牙遥控”模式，可通过蓝牙指令随时切换。
- **PD循迹控制**：采用五路红外传感器，通过加权平均法计算偏差，并使用PD算法动态调节轮速，实现平滑循迹。
- **蓝牙遥控与失联保护**：通过UART串口接收蓝牙指令，内置**300ms失联超时保护**，确保连接异常时小车自动安全停车。
- **PWM精准调速**：利用定时器实现100Hz软件PWM，精准控制电机转速与方向。
- **核心MCU**：8051 (STC89C52RC)
- **编程语言**：C (Keil C51)
- **关键外设**：红外传感器、HC-05蓝牙模块、L298N电机驱动
- **核心算法/机制**：PD控制、PWM、UART中断、环形缓冲区、非阻塞轮询
## 🔌 硬件连接
| 外设 | 连接引脚 | 功能说明 |
| :--- | :--- | :--- |
| 红外传感器 | P1.0 - P1.4 | 循迹信号输入 |这个引脚你自己改一下配置，我用的引脚是P1上顺手选的，看那个sensor.c文件改
| 电机驱动 | P2.0 - P2.5 | PWM与方向控制 |
| HC-05蓝牙 | P3.0 (RXD), P3.1 (TXD) | 串口通信 |
| 模式指示灯 | P3.7 | 循迹模式亮，遥控模式灭 |

> 详细引脚定义请参阅 `config.h` 和各个模块的源文件。

## 🚀 快速开始

1.  使用 Keil uVision 打开 `Project` 文件夹中的工程文件（`.uvproj`）。
2.  编译工程，生成 `.hex` 文件。
3.  使用烧录工具（如 STC-ISP）将固件下载到单片机。
4.  上电后默认进入**循迹模式**（指示灯亮）。通过手机蓝牙串口 APP 发送字符指令（如 `F`, `B`, `L`, `R`, `T`）即可切换到遥控模式或控制小车。

## 📁 项目结构
├── main.c # 主程序，模式调度
├── config.h # 全局参数配置（速度、PID、超时等）
├── motor.c/h # 电机PWM驱动
├── sensor.c/h # 红外传感器读取与偏差计算
├── control.c/h # PD控制算法实现
├── track.c/h # 循迹模式逻辑（含节拍控制）
├── remote.c/h # 蓝牙遥控指令解析与执行
├── uart.c/h # 串口驱动（含环形缓冲区）
├── timer.c/h # 定时器与系统节拍
└── system.h # 系统模式定义
